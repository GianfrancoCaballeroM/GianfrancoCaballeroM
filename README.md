**Advanced MongoDB Patterns Implemented:**

| Pattern | Implementation |
|---|---|
| **Capped Collections** | `auditoria_logs` initialized at startup `{ capped: true, size: 1048576, max: 1000 }` for circular audit writes |

## 🔍 Core Engineering Mindset

| Principle | Practice |
|---|---|
| **AI-Orchestrated Workflow** | Architecture, API design, DB schemas, and UX heuristics are human-led. Automated tools and AI agents accelerate execution. |
| **Spec-Driven Development** | OpenAPI contracts, BPMN flows, and traceability matrices always precede code implementation. |
| **Security by Design** | RBAC, OTP hashing, rate-limiting, and brute-force mitigation integrated proactively. |
| **Root Cause over Patch** | Defects investigated at database and architectural origins, avoiding superficial visual patches. |
| **Quality & Test Automation** | Unit tests, API validation via Postman, and automated E2E test suites with Katalon Studio. |
